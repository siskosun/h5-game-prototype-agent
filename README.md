# H5 Game Prototype Agent

Version: 0.1

A refactored DeepSeek Harness skill for building, modifying, debugging, validating, and delivering 2D H5 game vertical slices.

The 0.1 reset keeps the proven H5-specific strengths (material decision grilling, contract-first gameplay, Foundation Slice, production-core headless simulation, meaningful-choice/curriculum checks, mobile/player-facing QA, persistence evolution, and hash-bound release evidence) while adopting the strongest general game-development behaviors: inspect existing projects before editing, route work by task type, reproduce bugs before repair, use the minimum sufficient verification chain, preserve task boundaries, avoid over-engineering, and measure performance before optimization.

Primary entrypoint: `SKILL.md`.
