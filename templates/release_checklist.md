# Release Checklist

- [ ] DeliveryTarget matches user choice.
- [ ] Final result exists and has the promised entrypoint.
- [ ] Final hash/snapshot hash is frozen.
- [ ] Browser smoke uses the exact final result.
- [ ] Intended player loop completes.
- [ ] Blocking console/page/network/input errors are empty.
- [ ] Required mobile/layout/visual evidence is captured.
- [ ] Persistence paths pass when applicable.
- [ ] browser_report.json artifactSha256 matches the final result.
- [ ] No post-QA edits were made.
- [ ] Start/open instructions are exact.
